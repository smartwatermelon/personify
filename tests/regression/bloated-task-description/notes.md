# Notes

Exercises: Z (primary), V (primary), W (primary), and the Work register
classification steps.

## Why this case exists in two lengths

This is the case for issue #49's bullet 2: length alone must not buy an
exemption from the words-vs-idea ratio test.

Run it twice.

First as written: a ticket, so classification step 2, work register. Step 2
stops regardless of length, so padding the ticket does NOT move it to step 3.
That is deliberate, and it is worth knowing when building the second run: a
long ticket is still a ticket.

Second, as a long-form document. Recast the same content as a design doc of
roughly 1000 words in the identical padded register, framed to be read as a
piece of writing rather than as a message, so it genuinely reaches step 3 and
gets classified long-form. Step 3 exempts the text from forced informality:
complete sentences, standard capitalization. It does not exempt it from V, W,
or Z.

The regression to watch for is a long-form run that keeps the padding and
justifies it as "that register is just formal." Formal is precisely how the
polished-but-empty writing reads, which is the whole complaint this skill
exists to answer. Concretely, both runs must cut roughly the same proportion
of words and must both fix the title. Only the sentence shape should differ
between them.

If a future edit makes the long run noticeably less compressed than the short
one, that is the loophole reopening.

## Why the title matters as much as the body

Per Provenance, most of the manager's flagged examples were task titles and
descriptions rather than prose. A run that fixes the body and leaves "Data
pipeline work" as the title has failed the case even if every V and W check
passes, because the title is the part most readers see.

## Source

The description is a padded expansion of the group Z example already in
SKILL.md ("Ingest glue for the staging bucket, flat-file index, no managed DB
for a trial..."). Using the same underlying content keeps the case anchored to
the example the skill already commits to, while adding the V and W padding
that the skill's own example deliberately lacks.
